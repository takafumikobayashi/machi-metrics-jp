## Phase 3-B: 地域構造の拡張

- [x] 国土地理院の市区町村別面積を、2025年1月1日時点の人口密度用データとして取得・正規化
- [x] `density.json` を独立データセットとして公開し、概要一覧と自治体詳細で可視化
- [x] 人口密度だけで見た全国類似自治体のランキングを追加
- [x] 産業構造・農業構造の定義と一次情報を確定
- [x] 第一次・第二次・第三次産業の構成比を独立データセットとして追加
- [x] 自治体詳細で県内23市町の産業構造を積み上げ棒で比較
- [x] 既存の4指標を維持したまま、人口密度・地域構造・産業構造の全国ランキングを追加

人口密度、産業、農業のデータは、まず独立した比較軸として表示する。既存の人口類似度へ特徴量として混ぜるかどうかは、欠損、基準年、分布を確認した後に別途判断する。

構造比較は既存の人口類似度とは別モデルで計算する。人口密度モデルは人口密度のみ、地域構造モデルは人口密度と産業3部門、産業構造モデルは産業3部門のみを使う。農業比率は第一次産業の内訳であるため、複合距離には重ねず、産業パネルの補助指標として表示する。

産業構造は令和2年国勢調査（2020年10月1日現在）の第5-3表を使う。住民基本台帳の年次系列とは基準日・統計定義が異なるため、年次推移には接続せず、1時点の構成比較として表示する。農業比率は「うち農業」、第一次産業は農業・林業と漁業の合計とし、構成比の分母は産業分類可能な15歳以上就業者とする。
