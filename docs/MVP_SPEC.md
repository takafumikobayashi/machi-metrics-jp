# MVP仕様

最終更新: 2026-08-29  
対象リリース: `juki-2016-2025-hiroshima-v16`

## 1. ゴール

広島県23市町の2016〜2025年の人口変化を閲覧でき、任意の市町について全国の類似自治体を5件以上確認できる、公開可能な最小版を作ります。

MVPの価値はデータ項目の多さではなく、期間と定義が揃った人口の「変化」と「内訳」と「比較」を一つの導線で提供することです。

## 2. 対象範囲

### 含める

- 広島県23市町の俯瞰
- 2016年1月1日から2025年1月1日までの年次人口（10時点）
- 総人口と年齢3区分の人数・構成比
- 自然増減、出生、死亡
- 社会増減、転入、転出
- 2018〜2025年の転入元・転出先別人数（総数、10歳階級別）
- 10年人口増減数・増減率
- 全国自治体の同じ基礎指標
- 初版の類似自治体スコアと寄与内訳
- データ出典、定義、更新日、注意事項
- グラフと同じ値を読める表または代替表示

### 含めない

- 2026年の人口値
- 将来人口の推計や独自予測
- 政策効果の因果推論
- リアルタイムデータ
- ログイン、保存、コメント、自治体からの投稿
- 産業、農業、財政、ふるさと納税の本番表示
- 都道府県・国勢調査との混在比較

## 3. 画面

入口は「市町から見る」と「テーマで比べる」の2つに分けます（[DECISIONS.md](DECISIONS.md) D-037）。ヘッダーには「市町を探す」「テーマで比べる」「データについて」を置き、テーマの並び（人口、子育て支援、財務状況、ふるさと納税、自治体DX、補助金・交付金）はヘッダー、トップのカード、自治体詳細のタブで共通にします。

### 3.1 トップ `/`

目的: 自分の町を選ぶか、比べたいテーマを選ぶ。詳しい分析は各ページに任せる。

表示順:

1. タイトル、対象範囲、データ基準の短い説明
2. 市町を選ぶ入口（名前での絞り込みと23市町の一覧）
3. テーマのカード。各カードに県全体の代表値を1つ、その集計方法と基準日を添える
4. 県全体の概況（人口の主要指標とグラフ）
5. データ方針へのリンク

### 3.2 市町を探す `/municipalities`

目的: 23市町から1つを選ぶ。人口の主要指標で並べ替えて見比べる。

必須要素:

- 市町を選ぶ入口（名前での絞り込み）
- 23市町の地図
- 指標切替: 10年人口増減率、高齢者比率、子ども比率、直近期間の自然増減率・社会増減率
- 同じ指標の並べ替え可能な一覧
- 自治体詳細へのリンク

地図は発見の入口であり、情報取得の唯一の手段にはしません。境界データが準備できるまで、一覧を先に完成させてもMVP作業は継続できます。

### 3.3 テーマ別比較

目的: 1つのテーマについて、23市町を同じ物差しで見比べる。

| テーマ         | ルート        | 主な内容                                                         |
| -------------- | ------------- | ---------------------------------------------------------------- |
| 人口           | `/population` | 県全体の人口推移・人口動態、10年増減率のランキング、23市町の一覧 |
| 子育て支援     | `/childcare`  | カテゴリー別の制度比較（総合点や順位は付けない）                 |
| 財務状況       | `/finance`    | 歳入・歳出の構成、経常収支比率の分布、財政力指数                 |
| ふるさと納税   | `/donations`  | 受入額・件数・平均寄付額のランキング                             |
| 自治体DX       | `/digital`    | 分野別の実施項目数と、公表された割合                             |
| 補助金・交付金 | `/grants`     | 制度別の採択件数と、金額が公表されている分の合計                 |

各ページは「主要指標 → 中心となるグラフ → 詳しい内訳 → 数値表 → 出典」の順にそろえます。細かい数値表は初期状態で閉じ、グラフを先に読めるようにします。

### 3.4 自治体詳細 `/municipalities/[code]`

目的: 1自治体の全体像をつかみ、テーマごとに詳しく確かめる。

タブ:

| タブ           | ルート                              | 内容                                                         |
| -------------- | ----------------------------------- | ------------------------------------------------------------ |
| 概要           | `/municipalities/[code]`            | テーマごとの要点の数字（2つずつ）と、詳しいタブへのリンク    |
| 人口・人口動態 | `/municipalities/[code]/population` | 下記の表示順                                                 |
| 地域の特徴     | `/municipalities/[code]/profile`    | 人口密度、産業・農業構造、全国の類似自治体と「似ている理由」 |
| 子育て支援     | `/municipalities/[code]/childcare`  | 分野別の制度と条件                                           |
| 財務状況       | `/municipalities/[code]/finance`    | 歳入・歳出、経常収支比率、財政力指数                         |
| ふるさと納税   | `/municipalities/[code]/donations`  | 受入額・件数の推移と使途                                     |
| 自治体DX       | `/municipalities/[code]/digital`    | 項目別の取組状況                                             |
| 補助金・交付金 | `/municipalities/[code]/grants`     | 制度別の採択一覧                                             |

人口・人口動態タブの表示順:

1. 自治体名、基準日、総人口、10年増減率
2. 総人口の10年折れ線と値の表
3. 2016年と2025年の年齢3区分比較
4. 自然増減・社会増減の年次推移
5. 出生・死亡、転入・転出の内訳（数値表は初期状態で閉じる）
6. 転入元・転出先の上位地点と年齢階級別積み上げ表示
7. 出典、用語、注意事項

全国の類似自治体5件と「似ている理由」は、地域の特徴タブに置きます。初版では比較対象の自治体詳細も同じルートで表示できます。ただし地図・ナビゲーションの中心は広島県とします。

### 3.5 データ説明 `/about/data`

目的: 数字の意味、作成方法、限界を確認できるようにする。

必須要素:

- 一次情報の名称とリンク
- 人口の範囲、日本人・外国人住民の扱い
- ストックとフローの年の違い
- 年齢区分と構成比の分母
- 増減率・類似度の式
- 欠損、境界変更、丸めの扱い
- データリリースIDと生成日時

## 4. 指標

| ID                           | 表示名           | 定義                                                            |
| ---------------------------- | ---------------- | --------------------------------------------------------------- |
| `population_total`           | 総人口           | 日本人住民と外国人住民の合計。基準日現在                        |
| `population_change_10y`      | 10年人口増減数   | 2025年人口 − 2016年人口                                         |
| `population_change_rate_10y` | 10年人口増減率   | `(2025年人口 / 2016年人口 - 1) × 100`                           |
| `age_0_14_share`             | 子ども比率       | 0〜14歳人口 / 年齢把握済み人口 × 100                            |
| `age_15_64_share`            | 生産年齢人口比率 | 15〜64歳人口 / 年齢把握済み人口 × 100                           |
| `age_65_plus_share`          | 高齢者比率       | 65歳以上人口 / 年齢把握済み人口 × 100                           |
| `natural_change`             | 自然増減         | 出生数 − 死亡数。出典値とも照合                                 |
| `migration_change`           | 社会増減         | 転入数 − 転出数を基本とし、出典の調整項目がある場合は別列で保持 |

画面では人数を整数、比率を原則小数第1位まで表示します。計算途中では丸めません。

上表の `× 100` は画面表示上の定義です。処理内部と公開JSONでは比率を0〜1のまま保持し、百分率への変換と丸めは表示層でのみ行います。指標IDは上表のまま変えず、単位が比率であることは公開JSONのスキーマと `manifest.json` で宣言します（[DECISIONS.md](DECISIONS.md) D-014）。

## 5. 類似自治体

### 5.1 対象

- 全国の市、町、村、東京都特別区
- 政令指定都市の行政区は除外し、市全体を採用
- 比較対象年と10年起点の必須値が揃う自治体のみ
- 自自治体は結果から除外

### 5.2 初版特徴量

| 特徴量                 | 変換                      | 重み |
| ---------------------- | ------------------------- | ---: |
| 2025年総人口           | `log10(population_total)` | 0.35 |
| 2025年0〜14歳比率      | 比率                      | 0.15 |
| 2025年65歳以上比率     | 比率                      | 0.20 |
| 2016〜2025年人口増減率 | 比率                      | 0.30 |

各特徴量は全国候補集合の中央値と四分位範囲（IQR）でロバスト標準化し、重み付きユークリッド距離を計算します。IQRが0の特徴量はそのリリースでは除外します。

```text
z(x) = (x - median) / IQR
distance(a, b) = sqrt(sum(weight_i * (z(a_i) - z(b_i))^2) / sum(weight_i))
```

距離が小さい順に表示し、総合順位だけでなく特徴量ごとの差を提示します。「類似度100%」のような根拠の弱い百分率には変換しません。

欠損値の補完はMVPでは行いません。必須特徴量が一つでも欠ける自治体は類似検索候補から除外し、除外数をデータ説明ページに記載します。

## 6. UI・アクセシビリティ要件

- スマートフォン幅320pxから利用できる。
- 色だけで増減や選択状態を伝えない。
- すべての操作をキーボードで行える。
- グラフにタイトル、単位、期間、代替の値一覧を用意する。
- 増加・減少には記号と文言を併記する。
- `▲` を減少の意味に使わない。負号または「減」を使う。
- 地図が読み込めない場合も一覧から全機能へ到達できる。
- 主要ページの初期HTMLにタイトルと概要を含める。

## 7. 性能・運用要件

- ブラウザからe-Stat等へ直接問い合わせない。
- 公開用JSONはリリースIDで不変とし、最新版ポインタだけを更新する。
- 本番表示は静的またはキャッシュ可能なデータで成立させる。
- 同じ入力と設定から同じ公開JSONを再生成できる。
- 1自治体のデータ不備で全サイトが無言で壊れない。ビルド前検証で停止し、対象と理由を表示する。

## 8. MVP完了条件

- [ ] 23市町すべてに10時点の総人口がある。
- [ ] 年齢3区分の合計と分母の検証に合格する。
- [ ] 自然増減・社会増減の期間ラベルが人口基準日と区別されている。
- [ ] 全国候補集合の件数と除外理由が記録されている。
- [ ] 23市町すべてで類似自治体が5件以上表示される。
- [ ] トップ、市町を探す、テーマ別比較、自治体詳細、データ説明の各画面がモバイルとデスクトップで使える。
- [ ] 公開値から出典マニフェストまで追跡できる。
- [ ] `pnpm check` と `pnpm build` が成功する。
- [ ] 数字を含む主要画面を、データ仕様に照らして人が確認する。
