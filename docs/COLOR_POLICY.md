# カラーポリシー

最終更新: 2026-09-06

このサイトは広島県内23市町の統計を扱う非公式サイトです。広島県の公式サイトと誤認されないこと、色だけで意味を決めつけさせないこと、ライト・ダークテーマのどちらでも読み取れることを配色の前提にします。

## 色の役割

| 役割         | トークン                                 | 使い方                                                                                          |
| ------------ | ---------------------------------------- | ----------------------------------------------------------------------------------------------- |
| ブランド     | `--brand-*`                              | ヘッダー、ボタン、リンク、注記などUIのアクセント。グラフのカテゴリ色には使わない。              |
| 系列         | `--series-1`、`--series-3`、`--series-4` | 1つのグラフ内で系列を区別するための色。画面をまたいだ意味は持たせず、凡例または見出しを添える。 |
| 財務カテゴリ | `--finance-1`〜`--finance-9`             | 歳入・歳出の構成バー専用。カテゴリ間の区別だけを表し、良し悪し・順位・増減の意味は持たせない。  |
| 増減         | `--increase`、`--decrease`               | 増加・減少の方向を表す場合だけに使う。符号と「増」「減」の文字を併記する。                      |
| 年齢の階調   | `--age-band-*`                           | 年齢のように順序のある区分だけに使う。明度の順序で低年齢から高年齢を示す。                      |
| ニュートラル | `--paper*`、`--line`、`--chart-muted`    | 背景、罫線、未注目状態など。カテゴリの意味を表す色としては使わない。                            |

ブランド色はテラコッタ（`--brand-600: #c0532f`）を基準とします。県の公式色との混同を避けるため、ブランド色はデータ系列から分離します。

## グラフの原則

- 色は単独の情報源にしない。凡例、見出し、値、構成比などを併記する。
- 交互作用のあるグラフは、マウスホバーだけでなくキーボードフォーカスでも同じツールチップを表示する。
- 順序のないカテゴリにはカテゴリカル配色を使い、順序のあるデータにだけ階調を使う。
- 財務構成のように区分が多いグラフは専用の落ち着いた配色を使い、ブランド色・増減色・年齢色を流用しない。
- テーマ切替時も同じ役割の色が対応し、ラベルと罫線のコントラストを保つ。

実装上の色トークンは [`src/app/globals.css`](../src/app/globals.css) に定義し、判断理由は [`docs/DECISIONS.md`](./DECISIONS.md) に記録します。
