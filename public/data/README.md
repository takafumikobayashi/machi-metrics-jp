# Published data

検証済みのWeb向けデータだけを置きます。現在は広島県23市町・10時点の準備版で、類似自治体の候補は全国に接続済みです。

`latest.json` は `juki-2016-2025-hiroshima-v5` を指します。v5では、既存の総人口・年齢3区分に加えて、`extended/municipality/<コード>.json` に日本人住民・外国人住民の人口、人口動態、5歳階級別人口を収録しています。`municipalities.json` には全国の市・町・村と東京都特別区の候補マスターを収録し、`similarity.json` には広島県23市町から見た全国上位5件と、人口規模・0〜14歳比率・65歳以上比率・人口増減率の各単独ランキングを収録しています。類似自治体の除外理由は、人口0・年齢階級データなし・年齢把握済み人口0・年齢階級の非公表を原因別に記録します。公開済みリリースは上書きしません。
