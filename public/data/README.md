# Published data

検証済みのWeb向けデータだけを置きます。現在は広島県23市町・10時点の準備版で、類似自治体の候補は全国に接続済みです。人口密度と産業・農業構造は人口データとは独立した比較軸として収録しています。

`latest.json` は `juki-2016-2025-hiroshima-v10` を指します。v10では、既存の総人口・年齢3区分に加えて、`extended/municipality/<コード>.json` に日本人住民・外国人住民の人口、人口動態、5歳階級別人口を収録しています。`density.json` には2025年1月1日時点の行政区域面積、人口、人口密度を、`industry.json` には2020年10月1日現在の15歳以上就業者の産業3部門と農業の構成を収録しています。`municipalities.json` には全国の市・町・村と東京都特別区の候補マスターを収録し、`similarity.json` には既存4指標の上位5件と各単独ランキングを、`similarity-structure.json` には人口密度・地域構造・産業構造の別モデルによる上位5件を収録しています。類似自治体の除外理由は、人口0・年齢階級データなし・年齢把握済み人口0・年齢階級の非公表を原因別に記録します。公開済みリリースは上書きしません。

## リリース運用

- 公開済みのリリースディレクトリは上書きせず、`latest.json` だけを現行版へ切り替えます。
- v9以下は当面、ロールバック用の不変履歴として保持します。切り戻す場合は `latest.json` を対象リリースへ戻して再デプロイします。
- `.gitignore` は未追跡ファイル向けの設定であり、追跡済みの公開データやGit履歴を縮小しません。容量が問題になるまでは履歴を残し、将来必要になった時点でGitHub Releaseやオブジェクトストレージなどのバージョン付き保管先へ移す方針です。
