# Published data

検証済みのWeb向けデータだけを置きます。現在は広島県23市町・10時点の準備版で、類似自治体の候補は全国に接続済みです。人口密度と産業・農業構造は人口データとは独立した比較軸として収録しています。

`latest.json` は `juki-2016-2025-hiroshima-v14` を指します。v14では、既存の総人口・年齢3区分に加えて、`extended/municipality/<コード>.json` に日本人住民・外国人住民の人口、人口動態、5歳階級別人口を収録しています。`density.json` には2025年1月1日時点の行政区域面積、人口、人口密度を、`industry.json` には2020年10月1日現在の15歳以上就業者の産業3部門と農業の構成を収録しています。`migration-flow.json` には2018〜2025年の広島県23市町について、e-Stat参考表第1表・第2表に基づく転入元・転出先別の総数と10歳階級別人口を原本どおり収録し、`migration-summary.json` には表示用の地方別・都道府県別・広島県内23市町別の集計を収録しています。`municipalities.json` には全国の市・町・村と東京都特別区の候補マスターを収録し、`similarity.json` には既存4指標の上位5件と各単独ランキングを、`similarity-structure.json` には人口密度・地域構造・産業構造の別モデルによる上位5件を収録しています。類似自治体の除外理由は、人口0・年齢階級データなし・年齢把握済み人口0・年齢階級の非公表を原因別に記録します。公開済みリリースは上書きしません。

## リリース運用

- 公開済みのリリースディレクトリは上書きせず、`latest.json` だけを現行版へ切り替えます。
- v9以下は当面、ロールバック用の不変履歴として保持します。切り戻す場合は `latest.json` を対象リリースへ戻して再デプロイします。
- v9以下の `density.json`・`industry.json` は取得日時項目がない旧形式ですが、読み込み互換性を維持しています。v10以降の新規生成では取得日時を必須とします。
- `migration-summary.json` の地方別は、原本に個別掲載された都道府県の公表分を集計したものです。原本の「その他の県」は地方へ配分せず、独立した残余集計として保持します。原本に行がない地点は0人とみなしません。
- v14の地域間人口移動は、参考表第1表（転入）・第2表（転出）の移動者（外国人を含む）を使用し、0〜9歳、10〜19歳、20〜29歳、30〜39歳、40〜49歳、50〜59歳、60歳以上、不詳・その他の積み上げで表示します。第3表・第4表の日本人・外国人内訳は旧リリースとの互換性のため保持しますが、現行画面の主表示には使用しません。
- `.gitignore` は未追跡ファイル向けの設定であり、追跡済みの公開データやGit履歴を縮小しません。容量が問題になるまでは履歴を残し、将来必要になった時点でGitHub Releaseやオブジェクトストレージなどのバージョン付き保管先へ移す方針です。
