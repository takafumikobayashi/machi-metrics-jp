# Published data

検証済みのWeb向けデータだけを置きます。現在は広島県23市町・10時点の準備版で、類似自治体の候補は全国に接続済みです。人口密度と産業・農業構造は人口データとは独立した比較軸として収録しています。

`latest.json` は `juki-2016-2025-hiroshima-v9` を指します。v9では、既存の総人口・年齢3区分に加えて、`extended/municipality/<コード>.json` に日本人住民・外国人住民の人口、人口動態、5歳階級別人口を収録しています。`density.json` には2025年1月1日時点の行政区域面積、人口、人口密度を、`industry.json` には2020年10月1日現在の15歳以上就業者の産業3部門と農業の構成を収録しています。`municipalities.json` には全国の市・町・村と東京都特別区の候補マスターを収録し、`similarity.json` には既存4指標の上位5件と各単独ランキングを、`similarity-structure.json` には人口密度・地域構造・産業構造の別モデルによる上位5件を収録しています。類似自治体の除外理由は、人口0・年齢階級データなし・年齢把握済み人口0・年齢階級の非公表を原因別に記録します。公開済みリリースは上書きしません。
