# ひろしま人口ダッシュボード（仮）

広島県23市町の人口変化を、公的統計から分かりやすく見える化するプロジェクトです。人口の現在地だけでなく、直近10年の変化、年齢構成、自然増減・社会増減を一続きの文脈で示し、全国の似た自治体との比較につなげます。

現在はMVP準備段階です。まず住民基本台帳ベースの人口データに対象を絞り、データ定義と判断理由を文書として残しながら実装します。

## MVPの範囲

- 中心地域: 広島県の全23市町
- 基準データ: 総務省「住民基本台帳に基づく人口、人口動態及び世帯数調査」
- 人口スナップショット: 2016年1月1日〜2025年1月1日の10時点
- 主な指標: 総人口、年齢3区分、10年人口増減率、自然増減、社会増減
- 全国比較: 人口規模、年齢構成、10年人口増減率を用いた類似自治体検索
- 対象外: 現行年（2026年）の値、将来人口推計、独自予測、ログインや投稿機能

年の定義や日本人・外国人住民の扱いなど、詳しいデータ契約は [docs/DATA_SPEC.md](docs/DATA_SPEC.md) を参照してください。

## セットアップ

必要なものは Node.js 22 以上と pnpm 10 です。

```bash
pnpm install
pnpm dev
```

ブラウザで `http://localhost:3000` を開きます。

品質チェックは次の1コマンドにまとめています。

```bash
pnpm check
pnpm build
```

データ設定だけを確認する場合は `pnpm validate:data` を使います。

## リポジトリ構成

```text
.
├── config/                 # 期間、対象自治体、類似度などの人が管理する設定
├── data/
│   ├── raw/                # 取得した原本（Git管理外・編集禁止）
│   ├── staging/            # 原本を表形式へ展開した中間データ（Git管理外）
│   └── processed/          # 検証・指標計算後の成果物（Git管理外）
├── docs/                   # プロジェクトの中核となる仕様と判断記録
├── public/data/            # Webが読む公開用JSON（小規模なリリースはGit管理）
├── scripts/data/           # 取得、正規化、検証、公開の処理
├── src/                    # Next.jsアプリケーション
└── tests/                  # データ契約と計算ロジックのテスト
```

データ処理の詳しい運用は [data/README.md](data/README.md) にあります。

## プロジェクトの原則

1. 数字より先に、数字の意味と基準日を明示する。
2. 元データを手修正せず、再現可能な変換処理にする。
3. 比較は順位づけだけでなく、違いを理解する入口にする。
4. 小さく公開し、人口密度・産業・農業・財政などを独立して追加する。
5. 判断理由を `docs/DECISIONS.md` に残す。

## データの出典

主要な一次情報は、総務省の住民基本台帳人口・人口動態調査と政府統計ポータル e-Stat です。データを取り込む際は、具体的な配布ページ、取得日時、対象表、ファイルのハッシュ値をリリースマニフェストに記録します。

- [総務省｜住民基本台帳等](https://www.soumu.go.jp/main_sosiki/jichi_gyousei/daityo/index.html)
- [e-Stat｜政府統計の総合窓口](https://www.e-stat.go.jp/)

本サイトは公的統計を加工したプロジェクトであり、総務省または各自治体の公式サイトではありません。
