# Data workspace

このディレクトリは、一次情報から公開JSONを作るローカル作業領域です。具体的な定義は [../docs/DATA_SPEC.md](../docs/DATA_SPEC.md) を正とします。

## ディレクトリ

- `raw/`: 取得した原本。内容を編集しない。Git管理外。
- `staging/`: 原表の見出しや結合セルを解消した中間形式。Git管理外。
- `processed/`: 共通モデルへ正規化し、検証・派生計算を終えたデータ。Git管理外。
- `../public/data/`: Web向けの不変リリース。小規模なMVPではGit管理。

各空ディレクトリの `.gitkeep` だけを管理します。

## 原本の配置例

```text
data/raw/
└── juki/
    └── 2025/
        ├── source-file.xlsx
        └── source.json
```

面積原本は統計分野を分け、次の場所へ保存します。

```text
data/raw/area/R8_04_mencho.csv
```

産業・農業構造の原本は次の場所へ保存します。

```text
data/raw/industry/2020/2020-005-03.xlsx
```

`source.json` には、統計名、表名、URL、取得日時、SHA-256、ファイル名、利用条件を記録します。ブラウザで手動取得した場合も同じ情報を残してください。

## 禁止事項

- ExcelやCSVの値を直接修正して帳尻を合わせる。
- 欠損を0で埋める。
- 自治体名だけで複数年を結合する。
- 基準日人口と期間内の人口動態を同じ年ラベルだけで結合する。
- 公開済みのリリースディレクトリを上書きする。
